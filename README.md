# 📘 Livro Digital de Ocorrências

Sistema web desenvolvido para facilitar o registro e a gestão de ocorrências em condomínios.

## 🚀 Funcionalidades
- Cadastro e login de usuários
- Registro de ocorrências por unidade/casa
- Filtro por status (pendente, em análise, resolvida)
- Gestão de usuários e permissões
- Exportação de dados (Excel/PDF)

## 🛠️ Tecnologias
- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## ▶️ Como executar
```bash
pip install -r requirements.txt
python app.py
